# Como usar este site

## Navegação

- As **abas no topo** levam a cada disciplina.
- O **menu à esquerda** mostra as aulas, listas e materiais da disciplina aberta.
- O **sumário à direita** mostra as seções da página atual.
- A **busca** (ícone de lupa, ou tecla ++s++) procura em todo o site — experimente buscar "fork" ou "JOIN".

## Aulas

Toda aula segue o mesmo formato:

1. **Objetivos** — o que você deve saber ao final.
2. **Vídeo** — a aula gravada (quando houver).
3. **Slides** — para baixar em PDF.
4. **Conteúdo** — explicação com exemplos.
5. **Código** — exemplos completos para rodar.
6. **Para praticar** — exercícios rápidos e o link da lista.

## Código das aulas

Todo o código está na pasta [`codigo/`](https://github.com/edurdneto/Ciencia-da-Computacao/tree/main/codigo) do repositório. Você pode:

=== "Baixar tudo (recomendado)"

    ```bash
    git clone https://github.com/edurdneto/Ciencia-da-Computacao.git
    cd Ciencia-da-Computacao/codigo
    ```

    Para pegar as atualizações depois: `git pull`.

=== "Baixar em .zip"

    Acesse o [repositório](https://github.com/edurdneto/Ciencia-da-Computacao), clique em **Code → Download ZIP**.

=== "Copiar da página"

    Todo bloco de código tem um botão :material-content-copy: no canto superior direito.

## Encontrou um erro?

Clique no ícone :material-file-edit-outline: no topo de qualquer página para sugerir uma correção pelo GitHub, ou avise o professor.
