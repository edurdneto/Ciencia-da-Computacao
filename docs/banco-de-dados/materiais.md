## Ferramentas

- [PostgreSQL](https://www.postgresql.org/download/) — o SGBD da disciplina.
- [DBeaver](https://dbeaver.io/) — interface gráfica gratuita para vários SGBDs.
- [DB Fiddle](https://www.db-fiddle.com/) — testar SQL no navegador, sem instalar nada.
- [draw.io](https://app.diagrams.net/) e [BR Modelo Web](https://www.brmodeloweb.com/) — para desenhar diagramas ER.
